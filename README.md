# 🏏 React Cricket Live Scores  

A real-time cricket score tracker using CricAPI with light/dark mode toggle.

## Features  
- ⚡ Live match scores with auto-refresh (30s)  
- 📱 Responsive design  
- 🌗 Light/Dark theme toggle  
- 🏏 Team scores with wickets & overs
